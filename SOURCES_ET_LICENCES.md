# Sources et licences tierces

Ce projet pédagogique inclut des modules issus de l'écosystème MicroPython :

- `code/ssd1306.py` — pilote OLED SSD1306 ; voir la [source officielle MicroPython](https://github.com/micropython/micropython/blob/master/drivers/display/ssd1306.py).
- `code/urequests.py` — client HTTP léger issu ou adapté de [micropython-lib](https://github.com/micropython/micropython-lib).

La notice de licence fournie avec le projet est conservée dans [LICENSE_MICROPYTHON.txt](LICENSE_MICROPYTHON.txt). Avant toute redistribution hors du contexte scolaire, vérifier les attributions propres à chaque fichier.

**Données orbitales :** [Open Notify — ISS Current Location](http://open-notify.org/Open-Notify-API/ISS-Location-Now/).

Le rapport, la présentation, les illustrations et le code du projet pédagogique ont été réalisés en équipe. Ce dépôt forké conserve les contributions et l'historique du dépôt d'origine ; aucune licence open source générale n'est accordée ici pour les contributions originales.
